# Support

This is an independently maintained macOS preview, without a service-level guarantee. Codex changes may require compatibility repairs. Native Codex notebook support may eventually supersede it.

Report reproducible bugs in [GitHub Issues](https://github.com/shaevitz/codex-notebook-context/issues). Include OS/architecture, VS Code and Codex extension versions, extension version, a minimal synthetic notebook, and whether a new chat and a refreshed existing chat both fail. Review diagnostics before sharing: remove local paths and personal details. Never post actual private notebook text, credentials or transcripts.

Start with Show Diagnostics, confirm the same Codex home, inspect the exact hook in Codex /hooks, confirm the chat directory equals the workspace root, and reselect the cell after a reload. Untested Codex versions pause collection by default. A successful Preview is only eligibility evidence, not proof of actual Codex delivery.

For security issues, follow SECURITY.md rather than posting exploit details publicly. Contributions should include focused regression coverage and updated compatibility evidence. Keep runtime dependencies and unsolicited data collection out of scope.
